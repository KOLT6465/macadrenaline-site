Quick Start

  • Open Adrenaline from the menu bar and run Performance Check in Settings.
  • For live capture, press Start and select a game or moving app in Apple's sharing picker.
  • Use Windowed or Borderless mode when available and leave automatic frame generation enabled.
  • If access was denied, enable Screen & System Audio Recording for Adrenaline in macOS System Settings, then reopen the app.

Privacy

Adrenaline processes selected capture content locally on your Mac and does not upload captured content.
